# WEEX Signal Dashboard — для Vercel Drop

Read-only dashboard for WEEX Futures with Bybit fallback. No API keys, no orders, no connection to your trading account.

## Установка без GitHub

1. Скачайте `weex-signal-dashboard.zip` из ChatGPT.
2. На телефоне откройте https://vercel.com/drop , выберите **file** и загружайте ZIP целиком.
3. Выберите проект, например `weex-signal-dashboard`, затем нажмите **Deploy**.
4. Откройте полученный адрес `*.vercel.app`.

## Как работает

- Каждые 60 секунд, **пока страница открыта**, обновляет данные с `/api/signals`.
- Источник **WEEX** для 5м + 15м. Если хотя бы один запрос неудачен / устарел, переключается **целиком на Bybit**.
- Поддерживает BTC, ETH, XRP, SOL, ALGO, SHIB, DOGE, XAUT (золото на базе XAUT).
- Анализирует **только закрытые** 5-минутные свечи, подтверждает EMA-тренд 15 минут и пробой диапазона.
- Сигнал действителен **до трёх минут после закрытия** сигнальной свечи. После этого `ЖДАТЬ`.
- Сильный сигнал выделяется фиолетовым; обычный — отдельно.
- Отображаемые TP/SL — иллюстративные уровни ATR, а не биржевые ордера.
- Включение уведомлений браузера необязательно. Уведомления возможны **только пока страница активна** (в фоне не гарантируются).

## Важно

Это прототип без реальной статистической проверки/бэктеста стратегии. Сигнал не гарантирует доход и не является подтверждением цены исполнения на бирже. Не торгует автоматически. Для круглосуточной рассылки push/Telegram понадобится отдельный фоновой планировщик и сервис доставки; простой веб-сайт этого не обеспечивает.
