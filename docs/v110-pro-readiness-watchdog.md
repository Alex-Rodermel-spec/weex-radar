# WEEX RADAR PRO — наблюдаемость №108/№110 (без торговых прав)

Страница `/pro.html` — работающий read-only пульт, а **не** автономная система исполнения и не обещание заработка. Прямые ссылки с главной `/`.

## Откуда берёт данные

- `GET /api/signals?mode=health` — 32 рыночных потока, последний heartbeat cron и версия сборки.
- `GET /api/signals?mode=journal` — агрегаты 5М прогнозиста V4, сохранённые независимые снимки V5 и исторические метрики ML.
- `GET /api/paper-trading` — завершённые/открытые виртуальные позиции и накопленные модельные убытки, без счёта пользователя.
- `GET /api/signals?mode=v110-news` и `mode=v110-news-forecast` — проверенные новости и связь с реально отправленными прогнозами.

Все пять запросов делаются из браузера при открытии страницы, по кнопке и не чаще одного раза за пять минут, пока страница видима. **Нового серверного cron, публичного запроса рыночных котировок, API ключей, паролей или биржевых прав нет.** При ошибках информация считается неизвестной; успех не выдумывается. Пульт использует `textContent` для динамических значений, никогда не вставляет JSON как HTML.

## Что изменилось в V5

`forecastV5Independent.collectionDiagnostics` отражает фактическую работу имеющегося зашифрованного 20-минутного исследовательского журнала:
- `NO_SAMPLES` — снимков ещё нет.
- `RECENT_SAMPLES` — был снимок не старше 90 минут.
- `STALE_SAMPLES` — последний снимок старше 90 минут (не доказывает поломку; GitHub schedule может задерживаться).
- Количество независимых снимков, `MIXED` воздержаний, отдельно направленных `LONG_BIAS/SHORT_BIAS`, процент **покрытия** направленными прогнозами, 60-минутное окно активности и время последней заморозки.

`RECENT_SAMPLES` не значит, что V5 точен; `MIXED` — не ошибка данных и не «победа». Для полезности алгоритма нужен будущий исход закрытых свечей на достаточной, независимой выборке. Проценты удачных прогнозов и `PAPER` прибыль нельзя смешивать. Историческая ML-модель по-прежнему **shadow-only**, обучение и выпуск в №108 не разрешаются новым экраном.

## Критический финансовый контекст

Ни страница, ни этот релиз не включает реальную торговлю, не меняет плечо, маржу, TP/SL, модели отбора, ntfy, крипторынки или отправку ордеров. Пока стратегия убыточна в PAPER и не прошла независимые тесты, в пульте нет статуса «готов к автоторговле». Конкретные личные счета, API secret, личные уведомления на Android пульт не видит.

Тесты `test/v110-pro-readiness.test.mjs` проверяют отсутствие навязанных рыночных прогнозов, задержку/воздержания V5, синтаксис скрипта, разделение данных и торговли. Данный релиз не является повышением точности или прибыльности.
