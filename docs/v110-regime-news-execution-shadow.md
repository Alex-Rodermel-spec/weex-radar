# WEEX RADAR №110 — три параллельных исследовательских направления

Релиз Research Shadow. Живой №108 продолжает работать без изменений.
Все выводы гипотетические, результат не является торговым сигналом или PnL.

## 1. Режим рынка (№3)

Существующий `GET /api/signals?mode=backtest&symbol=XRPUSDT` теперь
добавляет `regimeStudy`: TREND_UP, TREND_DOWN, RANGE, VOLATILE,
MIXED, UNKNOWN. Метка использует ТОЛЬКО полностью закрытые
5m/15m свечи, доступные к историческому моменту решения. Сравниваются
последующие исходы отвергнутых и пропущенных фильтрами потенциальных
входов (разрез по режиму). Нет автоматического изменения порогов,
рынков, STRONG/NORMAL, уведомлений, заказов или «чтения будущего».

Пороговые значения — инженерные гипотезы, не наученная модель и
не вероятность прибыльного входа. Когорты разных дней и монет
сильно коррелируют.

## 2. Качество входа / издержки (№4)

В том же `backtest` появляется `executionShadowStudy`:
- сравнение отклонённых и пропущенных кандидатов, отдельно LONG/SHORT;
- смещение OPEN следующей 5m свечи относительно сигнального закрытия;
  доля уже пройденных >=10 bps — **только ретроспективный прокси**;
- оценка через 5/10/15m в обычной модели 8 bps комиссия и 3 bps
  проскальзывание на сторону и при стресс-сценарии
  +5 bps проскальзывания на сторону.

OPEN следующей свечи неизвестен при принятии решения. Это **не**
историческое восстановление котировки WEEX bid/ask, исполнения,
спреда, задержки ntfy, funding, очереди или фактической прибыли.
Положительное движение отклонённой сделки не означает, что
такую сделку вообще можно было безопасно открыть.

## 3. Публичные новости (№2)

`GET /api/signals?mode=v110-news` — только read-only сбор
структурированных событий из уже действующего GitHub
[NEWS RADAR issue #62](https://github.com/Alex-Rodermel-spec/weex-radar/issues/62).
Исследование работает отдельно от торговых уведомлений.

Структура для *будущих* проверенных исследователем комментариев:
`NEWS_RADAR_V110_EVENT {"eventId":"FED_release_20261112","category":"FED","publishedAt":"2026-11-12T18:00:00Z","detectedAt":"2026-11-12T18:00:33Z","sourceUrl":"https://www.federalreserve.gov/example","primaryTimeVerified":true,"planned":false}`

**Это пример формата, не реально обнаруженное событие.**
Данные в issue — пользовательские/исследовательские аннотации.
Даже `primaryTimeVerified:true` не доказывает подлинность:
нужна отдельная проверка исходной публикации и движения рынка,
и проверка, опережало ли обнаружение цену. Время статьи Reuters
не приравнивается к времени исходного заявления.
Первый запрос пока может показать 0 структурированных событий:
два прошлых наблюдения issue #62 не содержат точной
первичной временной метки и никогда не превращаются в вымышленные события.
Период исследования — 10–24 ноября 2026.

Нет автоматической торговли по новостям, платной подписки,
нового Cron, записи приватных топиков или сообщений Android.
Добавление оценок новостей к боевым LONG/SHORT возможно только
после независимого forward-теста с доказательством полезности.

## Существующее направление №1

`missedOpportunityStudy` из #115 остаётся без изменений:
исторические кандидаты 5m/15m, отфильтрованные или допущенные
старыми gate, разница движения цены 5/10/15m. Все четыре темы
теперь присутствуют в исследовательском контуре; рабочий
№108 не меняется.

## Использование

- `/api/signals?mode=backtest&symbol=BTCUSDT`
- `/api/signals?mode=backtest&symbol=NVDAUSDT`
- `/api/signals?mode=v110-news`
- `/api/signals?mode=health` — 32 рынка, cron, ntfy
- `/api/signals?mode=journal` — archived confirmed, learningShadow, depthShadowStudy

Ни один из отчётов не является разрешением на перенос новых фильтров в
боевые уведомления. Автопромоушен требует заранее установленного
независимого теста на реально опубликованных LONG/SHORT, учёта
издержек и отката при деградации.
