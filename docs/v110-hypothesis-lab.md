# WEEX №110 — автоматический поиск гипотез, исследовательский режим

Добавлена самостоятельная **ограниченная лаборатория идей** `lib/v110-hypothesis-discovery.mjs`: она анализирует реальные опубликованные прогнозы из существующего **шифрованного** журнала и создает **исследовательские гипотезы** по LONG/SHORT на основе заранее определённого набора правил. Это **не свободно думающая нейросеть**: метод детерминированный, прозрачный, проверяемый и не меняет торговлю.

## Что именно исследует

Исследование отделяет LONG от SHORT, чтобы сильные SHORT не маскировали слабые LONG. Для каждого направления оцениваются три идеи:
- исключить прогнозы с пометкой повышенного риска
- не догонять движение, когда цена уже прошла в нужном направлении 10 bps (0,10%) до оповещения
- исключить оба случая одновременно

Это гипотезы, а не утверждения, что фильтры повышают доходность.

## Предохранители

- Только реально отправленные и попавшие в зашифрованный журнал прогнозы с завершенными 15/30-минутными окнами.
- Хронологические **разные UTC-календарные дни**: минимум 3 дня обучения, 2 последующих дня отложенной проверки и 30-минутная временная граница; интервалы для одной монеты отстоят минимум на 30 минут.
- **Подбор идеи только на тренировочных данных.** Проверочная выборка используется для испытания единственного выбранного кандидата, не для повторной оптимизации. Нужны минимальные объёмы и улучшение не только доли благоприятных движений, но и средней цены.
- Тестируемый показатель **не равен прибыльности реальной сделки**. Кластеризация монет, проскальзывание, комиссии и повторное использование отложенных периодов требуют **отдельного нетронутого будущего forward-теста** до любого изменения живых правил.
- Если улучшение не подтверждено — `KEEP_108`. Если выдержало отбор — **только предложить начать независимый тест**, не «внедрить».
- Только при первом переходе в подтверждённый на отложенной выборке исследовательский статус предложение в **приватный WEEX STATUS** по старой системе №118. Никаких сообщений в trading LONG/SHORT и Forecast.
- Старые модули №108, №110, сигналы ntfy, цена открытия, сделки, Vercel cron, тарифы, секреты **не меняются**; новый scheduler, платный API и рыночные запросы не нужны.

## Где увидеть

`GET /api/signals?mode=journal` → `hypothesisDiscovery` — сводка качества, статус, шесть кандидатных идей, обучение и отложенный тест без раскрытия личных уведомлений или исходных строк. Существующий OIDC-защищённый `journal-export` пересчитывает её автоматически по мере пополнения архива, а при достижении исследовательского порога может направить в WEEX STATUS сообщение на ручное рассмотрение.

**Важно:** ещё не является LLM или автономной моделью, способной придумать произвольную новую стратегию. Для этого потребуется отдельная система с дополнительной валидацией; текущая версия сознательно безопаснее.
