# WEEX RADAR: Telegram — резервные оповещения

Chrome Push и Cron продолжают работать независимо. Telegram включается только после подключения личного бота. Никаких ордеров Telegram не отправляет.

1. В Telegram откройте официального **@BotFather** и отправьте **/newbot**. Придумайте имя и username (заканчивается на bot). Скопируйте выданный **Bot API Token**. Не присылайте токен в ChatGPT и не публикуйте в GitHub.
2. В Vercel → weex-radar → Settings → Environment Variables создайте **TELEGRAM_BOT_TOKEN** с токеном как Sensitive/Encrypted для **Production**.
3. После сохранения переменной переразверните Production, чтобы секрет появился в среде функции.
4. Откройте созданного бота в Telegram и отправьте **/start** с секретным кодом сопряжения, уже сохранённым в Production как **TELEGRAM_PAIR_CODE**. Получите код от владельца проекта; его нельзя публиковать в GitHub.
5. Существующий минутный Cron прочитает команду `/start` через Telegram `getUpdates`, свяжет первый личный чат, пришлёт **явно тестовое** сообщение. Chat ID копировать не требуется.
6. Команда **/status** проверит подключение, **/stop** выключит Telegram, не выключая Chrome Push.

**Безопасность:** уникальный токен бота только на сервере, личный chat ID и отметки доставки в Private Vercel Blob; проверка секретного кода; только один владелец; без публичного вебхука и без увеличения числа serverless-функций. Не подключайте webhook на этого бота, иначе getUpdates работать не будет. Только закрытые 1m/5m свечи и существующая проверка котировок, Bybit всегда обозначен отдельно. Доставка и прибыль не гарантированы; автоматические сделки выключены.
